# Z-Library — Scripting iOS

版本 0.1.1。底部包含最新、搜索、设置三个页面。

- 最新：显示最近收录、详情与分页。
- 搜索：关键词、语言、格式及出版年份筛选。
- 设置：登录个人账号，保存在 iOS Keychain；网页可以打开，但未验证可自动授权回跳。登录接口不可用时，可手动导入本人会话凭据。
- 下载：已授权账号的图书文件保存至「文件」App → Scripting → Z-Library；支持系统分享。
- 站点：设置中的 HTTPS 白名单域名；切换后需重新登录。

注意：接口为第三方整理的非稳定 Z-Library EAPI，登录和下载尚需 iPhone 实际账号验证；此预览不承诺所有站点都能访问。单个下载大小限制 150 MiB。仅下载有权取得的内容。
