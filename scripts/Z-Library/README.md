# Z-Library — Scripting iOS

版本 0.3.2。底部包含最新、搜索、设置三个页面。

- 最新：显示最近收录、详情与分页。
- 搜索：关键词、语言、格式及出版年份筛选。
- 设置：登录个人账号，保存在 iOS Keychain；网页可以打开，但未验证可自动授权回跳。登录接口不可用时，可手动导入本人会话凭据。
- 下载：已授权账号的图书文件保存至「文件」App → Scripting → Z-Library；支持系统分享。
- 站点：设置中的 HTTPS 白名单域名；切换后需重新登录。

注意：接口为第三方整理的非稳定 Z-Library EAPI，登录和下载尚需 iPhone 实际账号验证；此预览不承诺所有站点都能访问。单个下载大小限制 150 MiB。仅下载有权取得的内容。

## 0.1.1
- 最新收录在服务端返回 `{"success":1}` 而无书籍数组时，使用 `POST /eapi/book/search` 和 `order=date` 回退到最近添加排序。
- 最新页保留一个刷新入口。
- 底部增加退出 Tab，调用模态关闭后结束脚本，不退出网站账号。

## 0.2.0
- 最新收录直达按日期排序的中文搜索接口；第一屏缓存 5 分钟，手动刷新忽略缓存。
- 封面按原比例完整显示；详情介绍最多五行。
- 搜索界面折叠筛选，最新与搜索结果在列表末尾自动加载下一页（iOS 18+）。
- 下载可选择服务端实际返回的格式；存在 EPUB 时默认选 EPUB，服务端不提供时不做虚假转换。
- 已登录会话在进入前台、切换 Tab 时按 10 分钟节流调用 profile 检查；这是活动期校验，不保证服务端续期。
- script.json.remoteResource.url 指向固定 GitHub ZIP；手动执行 Scripting 的“更新脚本”即可拉取后续版本。
- 首次启用官方更新地址，需要从本版安装包升级一次。

## 0.2.1
- 修正详情页 ScrollView、主 VStack、信息区 HStack 等容器的全宽约束，避免状态文本出现前页面被压窄。
- 下载成功后将原下载按钮切换为“分享或另存文件”，不再重复显示两个按钮；切换格式后恢复下载操作。
- GitHub 安装包和脚本远程更新 ZIP 仍使用固定地址。

## 0.2.2
- 修复 0.2.1 详情页全宽 frame 默认居中导致的两处左右留白，所有全宽容器均显式设置 alignment: leading。
- 保留下载后切换为分享或另存文件的主按钮行为。

## 0.3.0
- 最新中文书籍列表通过 List 滚动几何值 + 末尾行出现/可视回调自动翻页；锁避免重复请求。
- 搜索页重建为标题、通栏关键词、时间范围/语言/格式/排序下拉菜单、居中半宽按钮、可切换“记住搜索偏好”。
- 搜索偏好仅在勾选后持久化关键词与筛选条件，取消勾选会清除保存值；翻页沿用发起搜索时的筛选快照。
- 排序接入 EAPI 的 relevance/date/year/popular；年份范围、语言、格式均透传接口。
- 官方 zh.z-library.sk 网页访问在当前 Dell 网络中返回自跳转 307，无法据此确认实时官网所有下拉选项，已对可访问 EAPI 做实测。

## 0.3.1
