# Rime Preview 0.3.56 · 工具栏性能对照开关（2026-10-14）

## 范围与冻结基线

- 唯一变更分支：perf/rime-startup-trace。正式 main 0.3.52、原生候选栏、九键 Lua、Rime Session、触摸与键盘布局均保持不变。
- 设置路径：预览版「Rime启动诊断测试」→「键盘设置」→「动作与工具栏」→「显示工具栏（性能对照）」；默认开启，修改后重新唤起预览键盘。
- 这是自定义工具栏视图开关，不是 iOS 系统工具栏。CustomKeyboard.setToolbarVisible(false) 原逻辑保持。
- 关闭后，仅 Rime 就绪且没有组合输入、没有候选词的空闲状态省略 CandidateBarSubscriber、CandidateBar、ToolbarStrip 和左右工具图标；用空白 VStack 保留原顶部高度。空白是为了让按键坐标保持不变。
- 尚未就绪/初始化出错时仍显示状态，组合输入或有候选时仍显示完整候选栏及展开入口。工具栏的剪贴板/常用语快捷入口关闭后暂时不可见，但重新开启即可恢复，相关功能和配置不删除。
- 存储仍使用原 toolbarPreferences 对象，新字段 showToolbar 默认 true，旧配置兼容。编辑工具按钮顺序保留原显示/隐藏状态。
- 不增加逐键检测、持久化采样、网络请求或额外线程；0.3.54/0.3.55 的候选与九键拼音状态隔离保持。

## iPhone 真机对照（待验收）

1. 在 Scripting 中确认仅「Rime启动诊断测试」升级到 0.3.56，正式键盘未变；保持「显示按键角标」现有值不变，对比工具栏开/关时转圈次数和交互流畅度。
2. 关闭工具栏，闲置时顶部应显示空白、按键不挪位置；输入九键/26 键时必须正常显示、选择、展开与滚动候选词；初始化提示及错误不能被隐藏。
3. 如仍有转圈，再单独切换角标，按「工具栏开/关 × 角标开/关」四组合测试，避免错判主因。
4. 关闭后工具栏入口暂不可用；仍可通过设置重新开启，重新唤起键盘恢复。若出现候选消失、触摸异常、键盘错位，回退 0.3.55。
5. 启动 JS 报告不包含真实首帧和转圈次数，不宜只根据启动毫秒数认定工具栏导致问题。

## 失败经验与不回归约束

- 不能把顶部整行无条件隐藏：它还承担候选和加载状态。
- 不能只把工具栏图标变透明：本次测试需要真正不创建其视图节点。
- 重排工具按钮若写入只有 items 的 toolbarPreferences，showToolbar 会复位为默认开启；必须保留其他字段。
- 关闭工具栏不应改变键盘请求高度或按键布局，否则对照混入另一变量。
- 目前无真实 iPhone 结果，不进入正式 main。
- 打包校验额外锁定了 ToolbarStrip.tsx 与正式 0.3.44 字节一致；KeyView.tsx 已在历史预览变更过，不能错误断言与 0.3.44 二进制归档一致，本次没有修改它。
