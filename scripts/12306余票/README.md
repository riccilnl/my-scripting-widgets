# 12306 余票查询 v0.2.0

Scripting 原生界面，支持直达余票、指定中转站的当日两段换乘组合、列车经停站查询。

底部使用原生 TabView（首页、退出）。点击退出关闭 Navigation 界面并调用 Script.exit()。

**限制**：暂不提供自动中转站推荐、跨日换乘、票价/折扣、后台定时查询或余票提醒。换乘等待时间仅根据当天两段车次时刻计算，尚未考虑站内步行及站点换乘要求。12306 可能限制第三方请求，手机实测前不能保证接口可用。

`script.json` 配置固定 GitHub 安装包 URL 和 3600 秒远程检查间隔；是否自动安装更新还取决于 Scripting 全局设置。

实现参考 Joooook/12306-mcp（MIT），未包含 MCP 服务。
