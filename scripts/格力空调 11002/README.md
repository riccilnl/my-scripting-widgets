# 格力空调 11002 · Scripting

版本：1.1.4

## 功能

- 局域网自动发现 `mid=11002`
- 自动绑定并缓存 MAC / IP / AES key
- 开关机
- 读取设定温度 `SetTem`
- 读取室内温度传感器 `TemSen`
- 使用步进器调整设定温度
- 每次调温后重新读取状态确认
- 自动兼容摄氏 / 华氏温标，不主动修改设备当前温标
- DHCP 地址变化或 key 失效时自动重新扫描 / 绑定一次
- Scripting Pro 控制中心开关

## 温度说明

多数格力 Wi-Fi 模块把 `TemSen` 编码为“实际摄氏温度 + 40”，脚本会自动解码；也兼容直接返回实际温度的固件。如果设备不提供 `TemSen`，室内温度显示 `--`。

摄氏设定范围按常见家用格力机型限制为 16–30°C；华氏模式对应 61–86°F。
